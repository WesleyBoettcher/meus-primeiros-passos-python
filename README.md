# Meus Primeiros Passos em Python 🐍

Bem-vindo ao meu repositório de estudos! Este espaço foi criado para documentar e acompanhar a minha jornada de evolução na programação. 

Todos os algoritmos e scripts aqui presentes são exercícios práticos desenvolvidos durante o meu aprendizado na linguagem Python, cobrindo desde conceitos fundamentais de lógica, operadores aritméticos e formatação de dados até estruturas condicionais e resolução de problemas do dia a dia.

## 🚀 O que vai encontrar aqui
* Scripts focados no desenvolvimento de raciocínio lógico.
* Aplicação prática de conceitos fundamentais da sintaxe do Python.
* Exemplos de automação de cálculos e tomada de decisões lógicas.
